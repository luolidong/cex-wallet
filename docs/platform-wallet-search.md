# 平台钱包查询验证

本文档验证 `资产管理 -> 平台钱包` 的分页和筛选能力。

## 1. 页面入口

```text
资产管理 -> 平台钱包
```

## 2. 查询能力

支持：

- 钱包 ID
- 钱包地址
- Token 符号
- 备注
- 链
- Token
- 钱包角色：热钱包、冷钱包、归集钱包、手续费钱包
- 状态：`ACTIVE`、`INACTIVE`

列表使用后端分页，默认每页 `20` 条。

## 3. 验证步骤

1. 进入 `资产管理 -> 平台钱包`。
2. 不输入条件，预期展示钱包列表和总数。
3. 输入钱包地址片段查询，预期只展示匹配钱包。
4. 按链筛选，预期只展示对应链的钱包。
5. 选择链后再按 Token 筛选，预期只展示对应 Token 的钱包。
6. 按钱包角色筛选，例如 `热钱包`。
7. 按 `ACTIVE` / `INACTIVE` 筛选。
8. 点击分页页码或切换每页条数，预期列表正常刷新。
9. 点击 `重置`，预期清空筛选并回到第一页。
10. 新增、编辑、停用、启用钱包后，预期列表自动刷新。

## 4. 接口

```text
GET /api/assets/platform-wallets
```

参数：

- `keyword`
- `chainId`
- `tokenId`
- `walletRole`
- `status`
- `page`
- `pageSize`
