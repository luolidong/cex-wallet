# 用户 KYC 等级管理验证

本文档验证后台用户 KYC 等级调整能力。

## 1. 等级说明

- `L0`：未认证。
- `L1`：基础认证。
- `L2`：高级认证。
- `L3`：机构或增强认证。

当前阶段只维护用户 KYC 等级字段，不直接绑定提现限额。提现限额仍在 `风控设置` 中按 Token 配置。

## 2. 页面入口

可以从两个地方调整：

- `用户管理` 列表中的 `KYC` 按钮。
- `用户详情` 顶部的 `调整 KYC` 按钮。

## 3. 验证步骤

1. 进入 `用户管理`。
2. 选择一个用户，点击 `KYC`。
3. 将等级从 `L0` 调整为 `L1` 或其他等级。
4. 预期用户列表中的 KYC 展示同步变化。
5. 进入该用户详情页，预期 KYC 展示同步变化。
6. 在用户详情页点击 `调整 KYC`，再次修改等级。
7. 进入 `审计日志`，预期可以看到 `修改用户 KYC` 记录。

## 4. 后端接口

```text
PUT /api/users/{id}/kyc-level
```

请求体：

```json
{
  "kycLevel": 1
}
```

后端只允许 `0` 到 `3`。
