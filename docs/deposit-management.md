# 充值记录页面验证

本文档验证后台 `充值记录` 页面。

## 1. 页面入口

启动后端和前端后，进入左侧菜单：

```text
充值记录
```

页面用于全局查询链上充值记录，方便按交易 Hash、充值地址、用户和状态排查。

## 2. 查询能力

支持筛选：

- `txHash`
- `fromAddress`
- `toAddress`
- 用户名
- 用户 ID
- 链
- Token
- 状态

列表使用后端分页，默认每页 `20` 条。页面每 `10` 秒自动刷新。

## 3. 验证步骤

1. 先完成一笔本地 Anvil 充值，并等待 scanner 入账。
2. 进入 `充值记录` 页面。
3. 不输入筛选条件，预期能看到最近充值记录。
4. 输入交易 Hash 的一部分查询，预期只展示匹配记录。
5. 输入充值地址或用户 ID 查询，预期只展示该用户相关充值。
6. 使用状态筛选 `CONFIRMED`，预期只展示已确认充值。

## 4. 权限说明

需要权限：

```text
wallet:read
```

充值记录页面只做查询，不提供手工改状态。异常入账、补账和冲正应通过后续专门的账务处理流程完成。
