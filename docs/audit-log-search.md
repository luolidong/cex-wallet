# 审计日志查询验证

本文档验证 `审计日志` 页面分页、搜索和筛选能力。

## 1. 页面入口

```text
审计日志
```

## 2. 查询能力

支持：

- 管理员用户名
- 对象 ID
- 摘要
- 详情 JSON
- 动作类型
- 对象类型

列表使用后端分页，默认每页 `20` 条，每 `10` 秒自动刷新。

## 3. 验证步骤

1. 进入 `审计日志`。
2. 不输入条件，预期展示日志列表和总数。
3. 输入管理员用户名关键词查询。
4. 输入对象 ID 查询，例如用户 ID、提现 ID 或账务流水 ID。
5. 按动作类型筛选，例如 `人工调账`、`修改用户 KYC`。
6. 按对象类型筛选，例如 `用户`、`账务流水`、`提现单`。
7. 点击分页页码或切换每页条数，预期列表正常刷新。
8. 点击 `查看`，预期详情抽屉正常展示。
9. 点击 `重置`，预期清空筛选并回到第一页。

## 4. 接口

```text
GET /api/audit-logs
```

参数：

- `keyword`
- `action`
- `targetType`
- `page`
- `pageSize`
