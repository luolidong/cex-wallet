# 地址管理页面验证

本文档验证后台 `地址管理` 页面。

## 1. 页面入口

启动后端和前端后，进入左侧菜单：

```text
地址管理
```

页面用于全局查询用户充值地址，并处理异常地址启停。

地址列表使用后端分页，默认每页 `20` 条。翻页、切换每页条数和筛选都会重新请求后端。

## 2. 查询验证

支持筛选：

- 地址
- 用户名
- 用户 ID
- 链
- 状态

建议测试：

1. 在用户详情页生成一个充值地址。
2. 进入 `地址管理`。
3. 用用户名或用户 ID 查询。
4. 预期能看到该用户的充值地址。

## 3. 启停验证

点击某条 ACTIVE 地址的 `停用`。

预期：

- 状态变为 `INACTIVE`。
- scanner 后续只匹配 ACTIVE 的充值地址，所以该地址不会继续作为有效充值地址入账。
- 审计日志出现 `停用充值地址`。

再点击 `启用`。

预期：

- 状态变回 `ACTIVE`。
- 审计日志出现 `启用充值地址`。

## 4. 权限说明

- `wallet:read`：可以查看地址管理页面。
- `wallet:manage`：可以启用、停用充值地址。
