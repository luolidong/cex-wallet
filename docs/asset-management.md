# 资产管理页面验证

本文档验证后台资产配置页面：

```text
资产管理
  -> 链配置
  -> Token 配置
  -> 充值/提现业务实时使用配置
```

## 1. 打开页面

启动后端和前端后，进入后台左侧菜单：

```text
资产管理
```

页面包含两个页签：

- `链配置`
- `Token 配置`

## 2. 验证链配置

在 `链配置` 页签点击 `Ethereum` 的编辑按钮。

可以修改：

- 链名称
- RPC URL
- 浏览器 URL
- 确认块数
- 扫描开关
- 提现开关
- 状态

建议测试：

1. 把 `提现` 关闭。
2. 去用户详情申请 ETH 或 USDT 提现。
3. 预期失败，错误码为 `WITHDRAW_DISABLED`。
4. 回到资产管理，把 `提现` 打开。

## 3. 验证 Token 配置

在 `Token 配置` 页签点击 `USDT` 的编辑按钮。

可以修改：

- 名称
- 合约地址
- 最小充值
- 最小提现
- 提现手续费
- 充值开关
- 提现开关
- 状态

页面输入使用展示单位，不需要手动换算最小单位。

例如 USDT decimals 是 6：

```text
页面输入 1
后端保存 1000000
```

建议测试：

1. 把 `USDT` 最小提现改成 `10`。
2. 去用户详情申请 `1 USDT` 提现。
3. 预期失败，错误码为 `AMOUNT_TOO_SMALL`。
4. 回到资产管理，把最小提现恢复成 `0` 或你希望的值。

## 4. 验证合约地址配置

如果重新部署了 MockERC20，可以在 `Token 配置` 里直接修改 USDT 合约地址。

保存后，以下服务会使用新地址：

- scanner ERC20 充值扫描
- signer ERC20 提现广播

修改后需要重启 scanner；Java API 不需要重启。
