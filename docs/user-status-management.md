# 用户状态管理验证

本文档验证后台 `用户管理` 的冻结和恢复能力。

## 1. 状态说明

- `ACTIVE`：正常用户，可以生成充值地址、申请提现。
- `FROZEN`：冻结用户，不能生成充值地址、不能申请提现。

冻结用户不会删除历史数据，也不会自动修改已有充值地址状态。

## 2. 页面入口

```text
用户管理
```

在用户列表的 `操作` 列可以执行：

- `冻结`
- `恢复`
- `详情`

## 3. 验证步骤

1. 进入 `用户管理`。
2. 选择一个 `ACTIVE` 用户，点击 `冻结`。
3. 预期用户状态变成 `FROZEN`。
4. 进入该用户详情页，预期页面显示冻结提示。
5. 预期 `生成充值地址` 和 `申请提现` 按钮不可点击。
6. 回到 `用户管理`，点击 `恢复`。
7. 预期用户状态变成 `ACTIVE`。
8. 再进入用户详情页，预期可以正常生成充值地址和申请提现。
9. 进入 `审计日志`，预期可以看到 `修改用户状态` 记录。

## 4. 后端拦截点

后端同时拦截以下入口：

- `POST /api/users/{userId}/deposit-addresses`
- `POST /api/users/{userId}/withdrawals`

即使前端被绕过，冻结用户也不能继续生成充值地址或申请提现。
