# 平台钱包启用验证

本文档验证 `资产管理 -> 平台钱包` 的停用和启用能力。

## 1. 页面入口

```text
资产管理 -> 平台钱包
```

## 2. 功能说明

平台钱包支持：

- 新增
- 编辑
- 停用
- 启用

账务对账会优先读取 `ACTIVE` 的 `HOT` 钱包作为热钱包覆盖余额来源。

## 3. 验证步骤

1. 进入 `资产管理 -> 平台钱包`。
2. 选择一个 `ACTIVE` 钱包，点击 `停用`。
3. 预期状态变成 `INACTIVE`。
4. 点击该钱包的 `启用`。
5. 预期状态恢复为 `ACTIVE`。
6. 进入 `账务对账`，确认热钱包余额仍可正常读取。
7. 进入 `审计日志`，预期可以看到：

```text
停用平台钱包
启用平台钱包
```

## 4. 后端接口

```text
DELETE /api/assets/platform-wallets/{id}
POST   /api/assets/platform-wallets/{id}/enable
```
