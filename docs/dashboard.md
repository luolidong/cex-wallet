# 仪表盘验证

本文档验证后台首页 `仪表盘`。

## 1. 页面入口

登录后台后进入：

```text
仪表盘
```

页面每 `10` 秒自动刷新一次。

## 2. 展示内容

- `待审核提现`：状态为 `PENDING_APPROVAL` 的提现数量。
- `已广播待确认`：状态为 `BROADCASTED` 的提现数量。
- `今日充值笔数`：今天检测到且已确认的充值数量。
- `今日确认提现`：今天确认成功的提现数量。
- `账务异常 Token`：账务对账或热钱包覆盖不足的 Token 数量。
- `异常服务`：Java API、Postgres、Redis、Scanner、Signer 中非 `UP` 的服务数量。
- `Token 资金覆盖`：展示用户可用、冻结、热钱包余额、覆盖差额和对账状态。
- `最近待处理提现`：展示最近的待审核、已批准、已广播提现。

## 3. 验证步骤

1. 打开 `仪表盘`，预期页面不再显示固定的 `0`，而是读取后端真实数据。
2. 创建一笔提现，预期 `待审核提现` 增加。
3. 批准该提现，预期 `待审核提现` 减少，最近待处理提现状态变为 `APPROVED`。
4. 广播该提现，预期 `已广播待确认` 增加。
5. Scanner 确认后，预期 `今日确认提现` 增加，`已广播待确认` 减少。
6. 停掉 Scanner 或 Signer，再刷新页面，预期 `异常服务` 增加。
7. 点击指标卡片，预期跳转到对应功能页面。

## 4. 设计说明

首页只展示跨 Token 可安全聚合的数量指标。不同 Token 的精度不同，不能直接把 ETH 和 USDT 的最小单位相加成一个总金额；金额类信息放在 `Token 资金覆盖` 明细中展示。
