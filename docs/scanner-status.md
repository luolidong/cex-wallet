# 扫描状态页面验证

本文档验证后台 `扫描状态` 页面。

## 1. 页面入口

启动 Java API、scanner 和前端后，进入后台左侧菜单：

```text
扫描状态
```

页面每 10 秒自动刷新，也可以手动点击 `刷新`。

## 2. 字段说明

- `链`：业务链配置名称。
- `扫描`：资产管理里的链扫描开关。
- `确认块数`：scanner 等待多少块后认为充值安全。
- `扫描器`：具体扫描任务名称，例如 `evm-native-deposit-scanner`。
- `最后扫描`：scanner 已扫描到的区块。
- `最后确认`：按确认块数计算后的安全区块。
- `滞后`：`最后确认 - 最后扫描`，正常情况下应为 `0`。
- `充值地址数`：当前链有效充值地址数量。
- `扫描器充值数`：当前扫描器负责资产类型的充值记录数量。
- `链充值总数`：当前链已入库充值记录总数，同一条链下多个扫描器会显示相同总数。
- `更新时间`：scanner 最近一次更新游标的时间。

## 3. 验证步骤

1. 启动 scanner。
2. 打开 `扫描状态` 页面。
3. 执行一笔 ETH 或 USDT 测试充值。
4. 等待页面自动刷新。

预期：

- Ethereum 至少出现 `evm-native-deposit-scanner` 或 `evm-erc20-deposit-scanner`。
- `最后扫描` 会推进。
- `更新时间` 会更新。
- 充值命中后，对应扫描器的 `扫描器充值数` 增加，`链充值总数` 也会增加。

## 4. 常见判断

- 页面没有游标：scanner 还没启动或还没成功跑过一次。
- `扫描` 是停用：到 `资产管理 -> 链配置` 打开扫描开关。
- `更新时间` 长时间不变：scanner 可能停止、RPC 不可用，或配置的 `API_BASE_URL` 不对。
- `evm-deposit-scanner` 是旧版本遗留游标，后台页面不会展示它。
