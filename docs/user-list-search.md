# 用户列表查询验证

本文档验证 `用户管理` 页面分页、搜索和筛选能力。

## 1. 页面入口

```text
用户管理
```

## 2. 查询能力

支持：

- 用户 ID
- 用户名
- 邮箱
- 手机号
- 状态：`ACTIVE`、`FROZEN`
- KYC：`L0`、`L1`、`L2`、`L3`

列表使用后端分页，默认每页 `20` 条。

## 3. 验证步骤

1. 进入 `用户管理`。
2. 不输入条件，预期展示用户列表和总数。
3. 输入用户 ID 查询，预期只展示该用户。
4. 输入用户名、邮箱或手机号关键词查询，预期展示匹配用户。
5. 按 `ACTIVE` 或 `FROZEN` 筛选，预期只展示对应状态用户。
6. 按 KYC 等级筛选，预期只展示对应等级用户。
7. 点击分页页码或切换每页条数，预期列表正常刷新。
8. 点击 `重置`，预期清空筛选并回到第一页。

## 4. 接口

```text
GET /api/users
```

参数：

- `keyword`
- `status`
- `kycLevel`
- `page`
- `pageSize`
